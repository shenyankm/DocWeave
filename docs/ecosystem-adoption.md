### 已修复问题与边界

- Markdown 隐藏 run 原先仍会输出，现与 TXT/结构提取一致过滤；隐藏注的正文也不泄漏。
- 注引用按 run 内部真实锚点放置；表格/链接内可见引用保留；缺失正文或缺失旧模型锚点发出诊断。
  代码块内引用移至块后并报警。只输出被可见引用触达的定义，不输出所有源注。
- keepNext 测量列表时暴露的 FPDF 未设置字体问题已修复。
- `pageBreakBefore` 不制造空白首页；keepNext 链仅在可放入一个区域时整体移动，过大组不会无限换页。
  两行孤行控制暂不覆盖含 tab 段落，也不等同于完整 Word 排版兼容。
- `provenance` 是原始解析快照中的 part/元素子路径；不是 PDF 坐标，也不会随 LDM 编辑自动重新定位。
- `preservation_report()` 比较解压后字节，保存不重置基线；它不证明 OOXML 语义或 Word 视觉等价。
