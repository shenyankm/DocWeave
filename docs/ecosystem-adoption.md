# Python 文档生态：对比与借鉴

本页是实现参考，不是项目能力的范围上限。全量目标、固定 26.9.0 基准和验收门槛以
[商业对齐计划](commercial-alignment-plan.md) 为准；使用方式见 [DOM 指南](docx-dom.md)
和 [转换与安全](enhanced-conversion.md)。

下表保留已积累的对照方向。局部测试或某次原生输出不代表完整格式/布局等价；历史
阶段的无引用调试与性能记录可从 Git 历史恢复；`benchmarks/` 保留指南、测试或复验器
引用的材料，以及独立外部引擎观察。不将旧测试数量、环境或 CI 状态写成当前结果。

## 证据与剩余边界

- [共同语义样本](benchmarks/ecosystem-corpus.json)、[注释/脚注样本](benchmarks/ecosystem-notes.json)
  用于内容与结构对照，不替代分页和像素检查。
- 早期性能测量移至 Git 历史；需要当前速度结论时，应在固定环境和共同语料上重新测量。
- 当前字体替换、塑形、外部引擎和内容损失边界见 [转换与安全](enhanced-conversion.md)。
- 完整布局、复杂共同样本、批量吞吐、标准认证及全部商业 API 的缺口仍保留在
  [全量台账](benchmarks/commercial-26.9-capabilities.json)。

重现各专项时使用 `benchmarks/` 中记录的版本、语料、配置和执行方法；测试/复验器仍
引用的原始输出及生成器保留。阶段叙述和失败调试过程可从 Git 历史恢复。
