WHAT YOU CAN BUILD

文档处理的四个入口

在脚本、服务与自动化流程中，处理受支持的文档内容。

01 / CONVERT

转换与生成

读取 DOCX、旧版 DOC、Markdown 与 TXT，输出 DOCX、Markdown、TXT 或 PDF。

02 / RENDER

中文 PDF

内置中文字体，可选备用字体与文字塑形；也可使用独立的 LibreOffice PDF 后端。

03 / EXTRACT

结构化提取

获取有序段落、表格、格式及来源内容，包括提取的脚注、尾注和页眉页脚。

04 / EDIT

DOCX 包级编辑

编辑受支持的文本、格式、表格、图片与超链接，保留未修改包部件的原始内容。

START SMALL

发行包：aspose-words-foss-enhanced

完整安装说明 ↗
01 — INSTALL
python -m pip install "git+https://github.com/shenyankm/DocWeave.git@dev"
02 — CONVERT
import aspose.words_foss as aw

doc = aw.Document("report.docx")
doc.save("report.pdf", aw.SaveFormat.PDF)
doc.save("report.md", aw.SaveFormat.MARKDOWN)
data = doc.to_dict()

需要可复现部署时，将 @dev 替换为已验证的完整提交哈希。请勿与 aspose-words-foss 同环境安装，两者共享导入模块。

KNOW THE BOUNDARIES

先验证，再交付。

转换会重建受支持内容，不是 DOCX 无损往返。包级编辑请使用 DocxDocument，复杂编辑可能被拒绝。

内置引擎不提供完整 Word 排版、PDF 读取或 OCR。复杂字段、修订、浮动内容、脚注与分节页眉页脚仍有保真限制。

请用代表性文档验证输出。不可信文档需隔离处理，资源限制不是安全沙箱。
